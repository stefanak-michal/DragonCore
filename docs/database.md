# Database

Framework does not include any 3rd library. You can choose your own.

## Neo4j

Let me introduce to the world of graph databases. Leading database is [Neo4j](https://neo4j.com/) and for communication is protocol with specification named [Bolt](https://github.com/stefanak-michal/php-bolt-driver). Try to give a try.
